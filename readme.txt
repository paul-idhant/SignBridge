Steps To Run 

1. Navigate to your project folder
(Replace the path with wherever your project folder is located, for example C:\Users\YourName\Downloads\signbridge-website-development)
PowerShell
cd "C:\path\to\signbridge-website-development"

2. Install the required dependencies
PowerShell
npm install

3. Start the development server
PowerShell
npm run dev

output a local link (usually http://localhost:5173)
launches site
